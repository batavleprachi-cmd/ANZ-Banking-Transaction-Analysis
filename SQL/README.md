# SQL – ANZ Banking Transaction Analysis

This repository contains SQL queries developed using MySQL for the ANZ Banking Transaction Analysis project.

**Activities Performed:**

- Retrieved all banking transactions using SELECT statements.
- Selected specific columns such as Customer ID, Transaction Date, Amount and Transaction Description.
- Retrieved limited records using LIMIT.
- Filtered transactions based on amount, customer age and gender using WHERE conditions.
- Identified salary transactions using transaction descriptions.
- Sorted and displayed the 10 highest transaction amounts using ORDER BY and DESC.
- Filtered transactions based on merchant states such as NSW and VIC using IN.
- Calculated total transaction count using COUNT().
- Calculated average transaction amount using AVG().
- Identified highest and lowest transaction amounts using MAX() and MIN().
- Analysed transaction counts by gender using GROUP BY.
- Identified customers with an average transaction amount greater than 200 using HAVING.

**SQL Concepts Used:**
- SELECT
- WHERE
- ORDER BY
- LIMIT
- IN
- COUNT()
- AVG()
- MAX()
- MIN()
- GROUP BY
- HAVING
