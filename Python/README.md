# Python – ANZ Banking Transaction Analysis

This repository contains the Python Jupyter Notebook developed for the ANZ Banking Transaction Analysis project.

**Activities Performed:**

- Imported banking transaction data using Pandas.
- Explored the dataset using `head()`, `info()` and `describe()` functions.
- Identified missing values across different columns.
- Analysed missing values in transaction-related fields.
- Checked total records, unique transaction IDs and duplicate transactions.
- Created customer age groups using Pandas `qcut()`.
- Converted transaction dates into a formatted date structure.
- Sorted transactions based on Customer ID and transaction date.
- Connected Python with MySQL using SQLAlchemy and MySQL Connector.
- Exported the processed DataFrame into a MySQL table named `bank_transactions`.

**Libraries Used:**
- Pandas
- SQLAlchemy
- MySQL Connector

**Key Dataset Details:**
- Total Records: 12,043
- Total Columns: 23
- Unique Transaction IDs: 12,043
- Duplicate Transaction IDs: 0

**File Format:** Jupyter Notebook (.ipynb)
