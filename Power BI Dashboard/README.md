# ANZ Banking Transaction Analysis – Power BI Dashboard

This repository contains the Power BI dashboard developed for the ANZ Banking Transaction Analysis project. The dashboard provides visual insights into banking transactions, customer information and transaction trends.

**Activities Performed:**

- Created KPI cards to display Average Transaction Amount, Number of Customers and Total Amount.
- Developed a donut chart to visualise Total Amount.
- Created a clustered column chart to analyse transaction amounts by Customer ID.
- Developed a line chart to analyse monthly transaction trends.
- Created a 100% stacked bar chart to visualise Average Transaction Amount by Transaction ID.
- Added interactive slicers for Gender, Age and Status to filter and explore the data.
- Designed an interactive dashboard to present key metrics and transaction insights.

**Visualisations Used:**
- KPI Cards
- Donut Chart
- Clustered Column Chart
- Line Chart
- 100% Stacked Bar Chart
- Interactive Slicers
