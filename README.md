## Project Overview

ANZ Banking Transaction Analysis is an end-to-end data analytics project focused on analysing banking transaction data using Python, SQL and Power BI.

## Tools & Technologies
- Python – Data cleaning and analysis
- MySQL – Data storage and SQL queries
- Power BI – Data visualisation and dashboard creation

## Project Workflow
1. Imported and explored banking transaction data using Python.
2. Cleaned and analysed the data using Pandas.
3. Connected Python data with MySQL.
4. Performed SQL queries to analyse transactions.
5. Created an interactive Power BI dashboard.
